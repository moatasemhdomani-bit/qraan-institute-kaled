# نظام معهد الصحابي الجليل خالد بن الوليد — المرحلة 1

موقع ويب حقيقي (Next.js + PostgreSQL) يغطي البنية الأساسية: المستخدمون والأدوار الخمسة، تسجيل العاملين،
الأفواج الخمسة، الحلقات، الدوام والعطل، وتسجيل الطلاب.

## التشغيل محليًا

قاعدة بيانات PostgreSQL محلية مُجهَّزة مسبقًا داخل `pgtools/` (بدون تثبيت نظامي، بدون خدمة ويندوز):

```bash
# تشغيل قاعدة البيانات (إن لم تكن تعمل)
pgtools/pgsql/bin/pg_ctl.exe -D pgtools/data -l pgtools/pg.log -o "-p 5433" start

# تشغيل الموقع
npm run dev
```

افتح: http://localhost:3000

### حساب الدخول الأول

- اسم المستخدم: `director`
- كلمة المرور: `Khaled@2026`

هذا حساب **مدير المعهد**. غيّروا كلمة المرور لاحقًا (لا توجد شاشة لتغييرها بعد ضمن المرحلة 1 — التغيير حاليًا
يتم عبر قاعدة البيانات مباشرة عند الحاجة).

## البنية

- `src/app/login` — شاشة الدخول
- `src/app/(app)` — الواجهة الداخلية المحمية (تتطلب جلسة دخول): لوحة التحكم، إدارة المستخدمين، سجل التدقيق،
  الأفواج، الحلقات، الدوام والعطل، الطلاب
- `src/lib` — قاعدة البيانات (Prisma)، الجلسات (JWT في كوكي httpOnly)، كلمات المرور (bcrypt)، سجل التدقيق
- `prisma/schema.prisma` — نموذج البيانات الكامل
- `prisma/seed.ts` — يزرع الأفواج الخمسة الثابتة وحساب مدير المعهد الأول

## ملاحظات مهمة

- **هذا موقع ويب** يُفتح من أي متصفح — وليس تطبيق سطح مكتب.
- كل الصلاحيات المذكورة في مواصفة المرحلة 1 مُطبَّقة فعليًا (وليست شكلية): مدير المعهد وحده يمنح دور
  "مدير المعهد" أو يحذف حساب إداري؛ الأفواج الخمسة ثابتة ولا تُضاف أو تُحذف؛ لا يمكن تسجيل طالب أو إنشاء
  حلقة قبل توفر البيانات التي تعتمد عليها.
- الصور (شخصية/طالب) تُحفظ في `public/uploads/`.
- عند نشر الموقع على خادم حقيقي لاحقًا: استبدلوا قاعدة البيانات المحلية بخادم PostgreSQL فعلي (Neon,
  Railway, أو خادمكم الخاص) بتحديث `DATABASE_URL` في `.env` فقط — لا حاجة لتغيير أي كود.
